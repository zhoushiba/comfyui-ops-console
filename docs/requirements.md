# 需求说明（Requirements）

## 1. 背景

本项目面向「AI 出图服务商」的日常运营场景：平台把 ComfyUI 的 GPU 算力包装成出图服务，通过代理商分销给终端创作者。运营同学需要一个后台，能看见任务与用量、把用量导出成 CSV 交给财务、按账期给代理商结算；研发同学需要一套可复现的 ComfyUI 接入层，覆盖提交、轮询、下载、转码和异常兜底。

对标岗位：宜宾智拟万像人工智能科技「React 前端开发实习生」，JD 明确要求以下 6 项能力：

| # | JD 要求 | 本项目对应 |
| --- | --- | --- |
| 1 | 运营后台用量与代理商结算数据 CSV 导出（服务端接口 + 页面交互 + 单测） | 用量/结算页 + `/api/export/*.csv` + `test/csv.test.ts` |
| 2 | ComfyUI 模拟服务 mock | `services/comfyui-mock`，按真实 HTTP 契约实现 |
| 3 | ComfyUI 接入：任务提交、结果轮询、图片回传、格式转换，覆盖失败/超时/服务未启动 | `comfyuiClient` + `poller` + `orchestrator` + `sharp` |
| 4 | 服务端 vitest 用例 + 客户端无头检查脚本 | `apps/server/test` 46 个用例 + `scripts/check-web.mjs` |
| 5 | 本地运行手册、ComfyUI 接入说明、兼容性评估报告 | `docs/runbook-local.md`、`docs/comfyui-integration.md`、`docs/compatibility-assessment.md` |
| 6 | 接口联调与上线验证 | `scripts/e2e-smoke.mjs`、Docker 编排、上线检查清单 |

## 2. 角色

| 角色 | 账号（种子） | 能做什么 |
| --- | --- | --- |
| 平台管理员 `admin` | `admin@ops.local / Admin@123456` | 全部功能：总览、任务、出图、图库、用量、代理商与结算、系统设置 |
| 代理商 `agent` | `studio@ops.local / Studio@123456` | 以代理商身份提交任务，任务归属 `agent_id=1`，用于结算 |
| 运营 `operator` | `operator@ops.local / Ops@123456` | 日常查看任务、图库、用量 |
| 创作者 `user` | `creator@ops.local / Creator@123456` | 提交出图任务、查看自己的任务与图片 |

> 登录后的数据权限按角色收敛；结算与系统设置仅管理员可操作（`store/auth.ts` 的 `canManage`）。

## 3. 用户故事

### 3.1 运营看板
- 作为运营，我要在首页看到今日/本月任务量、图片量、成功率、P50/P95 耗时、近 14 天趋势和失败原因，以便判断服务是否健康。
- 作为运营，我要看到代理商本月用量排行，以便发现异常消耗。

### 3.2 出图任务
- 作为创作者，我要选择模板、填写提示词与参数（尺寸、步数、CFG、种子、批量）并提交任务。
- 作为创作者，我要在任务列表里看到状态（排队/提交/运行/轮询/下载/完成/失败/超时/服务不可达）、进度和耗时。
- 作为创作者，失败任务要能一键重试，并且重复提交同一个 `clientRequestId` 不会产生重复任务。
- 作为创作者，我要在任务详情里看到生成的图片、尝试次数和失败原因。

### 3.3 图库与转码
- 作为运营，我要按任务、格式筛选图片，查看缩略图、原图、下载。
- 作为运营，我要把图片转换成 PNG/JPEG/WebP，调整质量，并批量转换、批量打包下载。

### 3.4 用量与结算
- 作为运营，我要按日期、代理商、状态、模型筛选用量明细，并导出 CSV（UTF-8 BOM，Excel 可直接打开）。
- 作为管理员，我要查看代理商结算单，按账期生成结算单（阶梯计价 + 分成），并执行「确认 → 打款」状态流转。
- 作为管理员，我要导出结算单 CSV，并能在审计日志中追溯导出行为。

### 3.5 接入与运维
- 作为开发者，我要用 mock 服务在本地复现 ComfyUI 全链路，不依赖 GPU。
- 作为开发者，我要能注入 `ok / slow / fail / partial / dead` 五种故障，验证失败、超时、服务未启动等异常路径。
- 作为运维，我要能通过 `/api/health`、系统状态页和 smoke 脚本做上线验证。

## 4. 功能范围

### 4.1 已实现（v1.0）

- 登录/登出/当前用户；HMAC 签名 token + scrypt 密码哈希。
- 运营总览：今日/月指标、状态分布、P50/P95、14 天趋势、最近任务、代理商排行、失败原因。
- 模板列表与参数校验（zod）。
- 出图任务：创建（幂等）、列表（筛选/分页）、详情、重试。
- 编排器：提交 → 轮询 → 下载 → 校验 → 缩略图/转码 → 完成；失败分类、指数退避、并发控制、重启恢复。
- 图库：筛选、原图/缩略图/下载、单图转码、批量转码、打包下载。
- 用量：统计（P50/P95/失败率）、明细分页、用量 CSV 导出。
- 代理商与结算：代理商列表/详情/结算预览、结算单创建/确认/打款、结算 CSV 导出。
- 设置：ComfyUI 地址/超时/并发等运行时配置、连接测试。
- 系统：状态、摘要、审计日志。
- Mock 服务：`/prompt`、`/history/{id}`、`/view`、`/queue`、`/system_stats`、`/object_info`、故障注入与进度。
- 测试与工程化：46 个 vitest 用例、E2E smoke、构建产物无头检查、Docker 编排、演示数据与截图脚本。

### 4.2 非目标（本期不做）

- 真实 GPU 集群调度、多租户隔离、计费支付通道对接。
- 对象存储（当前为本地磁盘 `storage/`）。
- WebSocket 实时进度（当前为 HTTP 轮询）。
- Electron 桌面封装（预留 `base: './'` 与 HashRouter，未提供 `apps/desktop`）。
- RBAC 细粒度权限（当前按角色粗分）。
