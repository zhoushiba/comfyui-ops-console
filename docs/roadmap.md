## 3. 风险与依赖

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 真实 ComfyUI 版本差异 | `/history` 结构、进度字段可能不同 | 接入层隔离 + mock 合约测试；版本探测 |
| 单实例内存队列 | 重启/多实例丢任务或重复执行 | DB 状态恢复；后续接外部队列 |
| 本地磁盘存储 | 多副本不可共享 | 生产接对象存储 |
| SQLite 并发写 | 高并发下锁等待 | 生产切 MySQL/PG |
| 真实 GPU 成本 | 演示无法覆盖真实时延 | mock 支持 slow/timeout 注入 |
| 种子默认密码 | 生产安全风险 | 上线清单强制改密 |
